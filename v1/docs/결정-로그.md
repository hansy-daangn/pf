# 결정 로그 — 왜 이렇게 했는가

- **피그마 = 원본.** 텍스트·이미지·구성은 피그마 원문이 기본값. 재해석 금지. 웹 이식 과정에서 생기는 문제(가독성·정렬·반응형)만 고친다. (2026-07, 사용자 지시)
- **신상 정보 전부 공개.** 주소·전화·개인메일 포함 — 포트폴리오 제출용이므로 사용자가 명시적으로 승인. 메일은 회사(daangn) 아닌 개인(gmail). (2026-07, 사용자 지시)
- **제출처별 버전은 파일을 나눈다.** 네이버 제출용은 연락처를 뺀 `naver.html`로 분리. 조건부 렌더링을 넣으면 두 상태를 계속 검증해야 하고, 소스에는 값이 남는다. (2026-08, 사용자 지시)
- **광고 성과 숫자는 첫 화면에 두지 않는다.** 스탯밴드 금지. 성과는 갤러리 상세(라이트박스)에서만. (사용자 지시)
- **기술 사항에서 항상 제외:** Reality Capture, Unreal, Stable Diffusion, PowerPoint, Notion, Obsidian, Veo3, ComfyUI, PostShot, Topaz, Figma 줄(AI·PT 그룹 전체). 2D·3D 두 줄만. (사용자 지시)
- **성향(about)·대형 컨택트 섹션 없음.** 연락처는 신분카드와 푸터로 충분. (사용자 지시)
- **그림자 금지(콘텐츠).** 챕터 보드·목차 카드의 그림자 제거, 플랫 반복 구조로. (사용자 지시)
- **갤러리는 순수 갤러리뷰.** 제목·태그는 호버 시 하단 좌측 오버레이로만. 스타일 스터디 타일도 여기에 혼합. (사용자 지시)
- **편집 게이트는 키워드 타이핑.** `#edit` 해시 폐기. 키워드는 소스에 있으므로 진짜 보안은 PAT(쓰기 권한)이다. (사용자 지시 + 구현 제약)
- **웹 가독성 보정:** 본문 200→300, 수상 표 글자 축소·행 그리드. 피그마 수치와 다르지만 "디자인적으로 고쳐라"는 지시에 따름. 대형 헤더의 200은 유지(시그니처).
- **C103 '연출의도' 행 제외:** 피그마 원본이 C102 텍스트를 복붙한 상태라 왜곡 방지 차원에서 그 행만 뺌. 원본 수정되면 되살릴 것.
- **슬로건 강조 효과:** 피그마의 `#7f0036 + 핑크 이미지 mix-blend screen`을 웹에선 `background-blend-mode:screen + background-clip:text`로 재현 — 시각 결과 동일, 구조는 단순.
