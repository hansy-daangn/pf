라운드에서 잘려나간 것
  • 전환 가치·모든 전환 가치(₩1,995,253,851·₩10,000,571,482) — 모델링 값이 조 단위로 널뛰며 실제 판단에 쓰이지 않는다. 애셋 보고서에서도 제외.
  • 타매체 표의 "비교하기" 버튼 열 — 행 자체를 호버/클릭 대상으로. 버튼 열 하나가 표 전체를 넓혔다.
  • 실증 블록의 등급 칩(매우 좋음·좋음…) — 값 색+상위%와 삼중 중복. 색약 대비는 상위% 텍스트가 담당.
  • 전체 기간 그래프 — 최근 8주 창으로. 23주를 다 그리면 최근 변화가 3px에 눌린다. 전체 기간 누적은 캡션 숫자로.
  • 비교군 2×2 행렬의 표 머리(이 매체 안/전 매체) — 행 라벨("광고그룹 · 전 매체 253개")에 흡수. 머리행이 데이터 4행보다 무거웠다.
