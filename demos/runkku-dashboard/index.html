런꾸 템플릿 릴스 인사이트

로컬러너스 챌린지 · 인스타그램 릴스(██초) · ██월 █일 게시 · ██월 ██일 인사이트 캡처 기준 · 챌린지 진행 중 중간 점검

훅과 저장은 계정 평소보다 좋았다. 하지만 █~█초 사이에 시청자가 몰려 이탈했고, 팔로워 밖으로 퍼지지 못했으며, 챌린지 참여로 넘어가는 길(링크 클릭 █회)이 사실상 없었다.

한눈에 결론

잘된 것
  • 건너뛰기 비율 ███%, 계정 평소보다 낮음 → 첫 자막 훅 ‘요즘 유행한다는 런꾸 템플릿’은 작동
  • █개 요인 중 저장 비율만 평소보다 높음 → ‘나중에 따라 해볼 템플릿’으로 받아들여짐
막힌 것
  • █~█초 사이 −██%p 이탈 → 끝까지 본 재생은 █%
  • 릴스 탭 유입 ██%, 공유 비율 평소 이하 → 추천 확산 없이 팔로워 피드 안에서 소비
  • 프로필 방문 ██ → 링크 클릭 █ → 챌린지로 가는 경로가 끊김
다음 영상에서 바꿀 것
  • █~█초에 완성된 런꾸 결과물부터, 촬영 세팅은 뒤로
  • 참여 방법은 엔딩이 아니라 앞부분 자막·캡션 첫 줄·고정 댓글에
  • 참여자 영상을 리포스트해 ‘공유할 이유’를 만들기

어디서 이탈했나

시청 유지 곡선. 빨간 구간이 가장 많이 빠진 █초.

재생 시점별 남아 있는 비율

인사이트 그래프를 █초 단위로 판독한 근사치

해석

  • █→█초 −██%p: 첫 프레임과 첫 자막은 무난
  • █→█초 −██%p: 전체 이탈의 ██%가 이 █초에 몰림. 절반이 빠지는 시점은 약 ██초
  • █초 이후는 초당 약 ██%p씩 완만하게 감소 → 본편이 지루하다기보다 도입 █~█초가 문제
  • 끝까지 본 재생은 약 ███회 → 엔딩에 넣은 챌린지 안내는 거의 보이지 않음
  • 가설(원본 컷과 대조 필요): █~█초에 결과물 대신 ‘벽에 폰 세우기’ 같은 촬영 세팅이 나오면, 완성본을 기대한 시청자가 넘김
  • 판독 검증: 곡선 아래 면적 █초 ≈ 공식 평균 조회 시간 █초

반응의 질

인스타그램이 도달에 중요한 순서로 매긴 █개 요인. ‘평소 대비’는 이 계정의 다른 릴스와 비교한 값.

해석

  • 반응 총 ███건, 도달 대비 ██%
  • 저장 ██ > 공유 ██, 저장이 좋아요의 ██% → ‘보관해 두는’ 템플릿형 콘텐츠의 정상 신호
  • 댓글 █ · 리포스트 █ → 챌린지인데 ‘나도 할게’ 같은 참여 선언이 거의 없음
  • 중요도 █위인 공유 비율이 평소 이하 → 추천 노출이 커지지 않은 직접 원인

해석

  • 피드 ███% + 팔로워 ███% → 기존 팔로워 피드에서 소비된 영상
  • 릴스 탭 ██%, 검색 ██% → 비팔로워 추천 노출은 미미
  • 누적 조회가 일반 릴스 곡선과 거의 겹침 → 계정 평균 수준, █차 확산 없음
  • 첫날에 전체 조회의 약 ██% 발생 → 성과는 게시 ██시간 안에 결정. 다음 영상은 게시 직후 스토리·당근모임 채널을 동시에 밀어야 함

질문에 대한 답

  • 연령별 액션은 이 데이터로 직접 확인 불가: 인스타 인사이트는 좋아요·저장·클릭을 연령별로 나누지 않음
  • 시청자는 ██~██세 ███%, 여성 ███%, ██~██세는 ██%
  • 팔로워 비중이 ███%라, 이 분포는 영상이 새로 끌어온 연령보다 계정 팔로워 구성을 거의 그대로 반영했을 가능성이 큼
  • 판단법: 계정 전체 팔로워의 연령 분포와 비교 → 팔로워보다 비중이 높은 연령이 이 영상에 더 반응한 연령
  • 타깃이 ██대 초중반(런꾸 유행 주 사용층)이었다면 미달, ██~██세 직장인 러너였다면 적중

마감 후 확인할 데이터

  • 템플릿 사용 수: 릴스 템플릿(오디오) 페이지의 사용 릴스 수 = 가장 직접적인 전환
  • 챌린지 해시태그 게시물 수 + 참여자 표본: 참여자 프로필 ██~██개를 열어 연령대·성별 추정 → ‘기대 연령에서 액션이 있었나’에 대한 실제 답
  • 당근 앱 유입: 소개 링크에 UTM을 달아 로컬러너스 페이지 방문·모임 가입까지 추적
  • 계정 팔로워 인구통계: 위 연령 비교의 기준값
  • 스토리 재공유 효과: 스토리 유입 █% → 링크 스티커를 붙인 스토리는 릴스보다 클릭 전환이 쉬움
출처: 인스타그램 릴스 인사이트 화면 █장(개요·참여·타겟 탭). 이탈 곡선과 누적 조회 추이는 그래프를 판독한 근사치이고, 나머지는 화면의 표시값. ‘평소 대비’ 판정은 인스타그램이 이 계정의 일반 릴스와 비교해 표시한 값.
