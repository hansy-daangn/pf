여러 업종 몽타주는 되고(+██%), 같은 업종 교차 편집은 안 됐어요(−██%)한 사람 서사 없이 빵집 세 곳을 7조각으로 오가면 짜집기로 보여요→ 업종 다른 3명, 증인당 한 블록, 교차 편집 없음
숫자 먼저(+█%) > 계기 먼저(−█%)같은 3명인데 순서만 달랐어요→ 0초에 ‘80%’ 인용
반론 1·2위는 ‘속을까’(██%)·‘될까’(██%)‘되나요?’ 질문이 ‘안 돼요’ 단정보다 4배 많아요. 아직 결론을 못 낸 상태예요→ ‘될까’엔 손님 말·채팅 화면, ‘속을까’엔 “하루 금액을 설정이 가능해요”
‘비싸다’보다 ‘얼마?’를 6배 더 물어요가격 공포보다 기준이 없는 상태예요→ 실리제롬이 직접 “5000원부터 … 빵 한두 개”, 엔드카드 “하루 예산은 5천 원부터, 사장님이 정해요”
불만 1위 “노출·클릭은 되는데 전화·방문이 없다”‘클릭 = 성과’는 대행사 보고서 말투로 들려요→ 마이디 ‘클릭·충전’ 대사는 뺐어요
광고주 업종 상위 3개 = 서비스·상품 판매·음식점증인 업종과 같아요. 교육(███%) 증인은 촬영본에 없어요→ 한계로 남겨요(다음 촬영 때 학원 원장님)

  • 이탈 사장님 A의 “해 봤는데 안 됐다”에 직접 답하는 대사는 없어요. 손님 말·채팅 화면·사장님의 결정으로 간접적으로만 답해요.
