> 다음에 이어 작업할 때 이 문서만 읽으면 되도록, 결정·구조·규칙을 두괄식으로 남긴다. v1 맥락은 `v1/docs/`.

## 1. 결론
- **무엇**: 영상 플랫폼형 포트폴리오. 홈(피처드+행) · 작업(라이브러리+검색) · 도구 · 자동화 · 이력서 4탭 + 전체화면 **상영관 플레이어** + PiP.
- **왜 이 형태**: 사용자 확정 — "애플뮤직의 홈 + 상영관 플레이어 + 애플뮤직형 이력서, 하단 재생바 대신 PiP, 넷플릭스·쿠팡플레이·왓챠·애플TV식 '보는 경험'". 하나의 사이트로 인지되는 통일성.
- **데이터는 한 곳**: `data/works.json` 61건(grade 1·2 = 45건 노출, 3 = 숨김). 수정 → `python3 src/build.py` 재빌드.
- **수치 정책**: 실제값은 저장하지 않는다. `metrics[].digits`(자릿수)만 두고 `.rd` 검정 바로 표시. 공개 상대값은 facts 검증 3건만(찐당근 3D 세트 약 1/3·1/5, 봄 키워드 1:1 완주율 약 2배, 10주년 영상 상위 약 1.5%).

## 3. 구조 (2026-11-01 단순화)
- `src/build.py` → `index/works/tools/resume.html` + `css/site.css` + `js/site.js` + `w/<id>.html`(공유) + sitemap·robots·404. **`data/`는 원본 — 빌드가 덮어쓰지 않음.** 파생물(썸네일 WebP·16:9 합성 포스터·피처드 첫 프레임)은 `assets/thumb`·`assets/poster16`·`assets/poster/bb`에 자동 생성.
- **영상 = 2종만**: `assets/v/<id>.mp4`(1080p) · `assets/v/<id>.sd.mp4`(720p, 원본이 720p 이하면 없음). 추가 규격은 `<id>-2.mp4`…. 호버·피처드는 같은 파일을 정해진 초부터 재생(별도 미리보기·클립 파일 없음). 데스크톱 상영관·피처드 = 1080p, 모바일·데이터 절약·확장 카드 = 720p.
- **이미지 소재**: `assets/i/<id>-<n>.<ext>` → 상영관 아래 갤러리.
- **works.json media**: `poster` · `shot`(도구 화면) · `videos[{label,hd,sd,w,h,dur}]` · `images[{label,src,w,h}]` · `start`(호버 시작 초) · `billboard[시작,끝]`(피처드 구간) · `youtube`.
- **원본 → 영상**: `masters/`(깃 제외) + `data/media_map.json {id: {videos:[원본파일…]}}` → `python3 src/media.py [id]` (파일당 48MB 상한).
- `src/site.js` 순서: 영상 고르기 → 확장 카드(매번 새 video 요소, 포스터 유지 → 이전 장면 안 남음) → 행 화살표(헤더 우측 상시, 끝이면 비활성) → 피처드(구간 재생 후 다음, 화면 밖·상영관·탭 숨김이면 멈춤) → 상영관(이미지 갤러리·비슷한 작업·다음 작품 5초·규격 전환 시 위치 유지) → 작업 필터+검색 → 도구 런처 → 딥링크 `?w=<id>`, `?reel`.
- **레이아웃**: 최대 폭 1440px(`--maxw`) + 좌우 여백 화면의 4%(16~64px, `--gut`). 피처드 기본 = 풀블리드(폭 1440 제한, 그라데이션 위 제목, 내비 투명) — 사용자 선호. 항상 재생, 진행 바·넘김은 영상 시간 기준.
- **2026-11-01 밤 구조(실시간 렌더 + 화면 편집)**: 홈 피처드·줄, 작업 그리드는 `src/site.js`가 `#pf-data`(works·home·design·derived)로 그리고, 로드 후 `data/*.json`을 no-cache로 다시 받아 바뀌었으면 다시 그림 → 편집 저장이 빌드 없이 반영. `data/derived.json` = 빌드가 만든 파생 이미지(16:9 썸네일·피처드 첫 프레임·호버 첫 프레임, `from` 서명이 지금 데이터와 같을 때만 사용, 다르면 원본 + CSS 블러 채움).
- **편집(/edit/)·디자인(/design/)**: 브라우저에서 GitHub API(사용자 토큰, localStorage `pf.gh`)로 `data/works.json`·`home.json`·`design.json`·`assets/poster/e/*.jpg`를 직접 커밋. 저장 시 최신 원격 파일 위에 바뀐 칸만 얹음. **로컬 작업 전 반드시 `git pull --rebase`** (사용자 편집 커밋이 main에 쌓임).

- `demos/<slug>/index.html`: 자체 호스팅 체험판. `cr-live`·`kf-live` = 사용자 원본 HTML + 앞단 가짜 응답(fetch 가로채기), 실서버 주소는 `.invalid`로 교체. 다시 만들기: `/home/claude/pf_work/crlive/tools/build.py`, `/home/claude/pf_work/kf_live/build.py`.

## 4a. 운영 규칙 (사용자가 직접 바꾸는 것)
- **자동 연결(2026-11-08)**: 토큰은 기기별 localStorage `pf.gh`. `/upload/`에서 처음 연결하면 토큰을 무작위 256bit 키로 AES-GCM 암호화해 `data/gh.enc` 커밋 + 키는 '내 전용 링크' `…/upload/#k=<키>`에만(서버로 안 감). `js/key.js`(upload·edit·design에 포함)가 `#k=`를 보면 풀어서 `pf.gh` 저장 후 새로고침. 이미 gh.enc가 있으면 덮지 않음(옛 링크 보호), '새 링크 만들기'만 갱신.
- **작품 올리기 `/upload/`**(2026-11-08, 단일 파일 `upload/index.html`, 빌드 대상 아님): 파일 + 정보 입력 → Git Data API 커밋 1회(blob → tree → commit → ref, 422면 최신 위에 재시도) → 배포 후 `data/works.json` 확인되면 '사이트 반영됨'. 새 작품 id = `up_YYMMDD_HHMMSS`. 경로 `assets/v/<id>[-n].mp4` · `assets/i/<id>-n.<ext>` · `assets/poster/<id>[-n].jpg`(이미 있는 이름은 피함). 투명 없는 PNG는 브라우저에서 JPG(0.92)로. sd(720p)·derived는 없음 → 사이트는 원본·블러 대체로 표시, 로컬 `media.py`·`build.py` 돌리면 채워짐.
- **대응 범위**: 데스크톱(1440·1920) 중심. 모바일은 **데스크톱 화면을 비율 그대로 축소**(공개 페이지 전부 viewport `width=1200`, 편집 화면만 폰 폭) — 폭은 슬라이더 `mvw`. 태블릿 등 별도 대응 없음(2026-11-01 사용자 지시, 2026-11-02 홈 포함 전부 축소로 확정)
- **도구는 도구 탭에서만**: `group` tools·research는 홈(피처드·대표·재생목록)·작업 탭·상영관 비슷한 작업·편집기 고르기 창에서 제외(`PF.isTool`, `MDATA`)
- **홈 구성**: `data/home.json` — `billboard`(피처드 순서) · `rep`(대표 작업 순서, `repTitle` 이름, `repHidden` 숨김) · `rows`(재생목록: `title` + `ids` 또는 자동 `kind`, `hidden`). 자동 목록은 편집기에서 순서·구성을 바꾸는 순간 `ids`로 고정.
- **편집기 `/edit/`**(src/edit.js·edit.css): 선택 → 오른쪽 패널(작품: 타임라인·썸네일 캡처·재생목록 체크·정보·노출 / 재생목록 전체·하나: 유튜브식 편집). 끌기는 id 기준·가장자리 자동 스크롤. 저장 = localStorage 초안 `pf.draft` + 새 이미지 IndexedDB `pf-edit` → 토큰 있으면 Git Data API 커밋 한 번(이미지 먼저) → 사이트 파일 확인 후 '사이트 반영됨'. 타임라인 필름스트립 = 빌드가 만드는 `assets/film/<id>_<k>.jpg`(30장면, derived.json `film`, 편집 페이지에만 포함). `/design/`(모듈 선택 + 미리보기, 초안·되돌리기·자동 재시도). 예전 붙여넣기용 `src/apply_edit.py` 예비.
- **분류**: `kinds`(3d·ai·motion·owned·image·personal·tools). `type`=종류, `contrib`=기여도, `dur`=길이, `highlight`=특별 성과 한 줄.
- **도구 설명**: `copy.one/what/proof/try` — 노션 「hansy 업무」 기준, 짧게.
- **제외**: `grade: 3`. 분석·리포트·버스·API Nav 등.
- **도구 체험판 원칙**: 원본 HTML 그대로 + 데이터만 예시. 원본 사이트·실데이터·Supabase는 건드리지 않음. 재디자인·가짜 목업 금지.
- **상영관**: 영상이 화면을 채우고, 스크롤하면 아래에 정보·이미지 소재·비슷한 작업. 자동으로 가리지 않음.
- **점검**: `python3 src/check.py`(용량·누락·콘솔 오류).
