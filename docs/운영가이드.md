# 포트폴리오 사이트 운영 가이드

- 사이트: https://hansy-daangn.github.io/pf/
- 레포: `hansy-daangn/pf` (main 푸시 = 배포, 1~2분)

## 1. 화질 원칙
- **화질은 일부러 낮추지 않는다.** 원본(마스터)은 `masters/`(깃 제외)에 두고 3단으로 자동 인코딩
  | 단계 | 용도 | 규격 |
  |---|---|---|
  | hd | 상영관·전체화면·데스크톱 | ≤1920, CRF20, 최대 8Mbps (가벼운 h264는 그대로 복사) |
  | sd | 모바일(폭<900)·데이터 절약 | ≤1280, CRF24, 3Mbps |
  | 미리보기 | 카드 호버 | 960, 6초, 무음 |
  | 빌보드 클립 | 홈 상단 | hd에서 지정 구간만 잘라냄 |
- 실행: `python3 src/media.py [작업id …]` (`--force` 재인코딩)
- 원본 연결표: `data/media_map.json`

## 2. 호스팅
- 지금: GitHub Pages (게시 한도 1GB, 월 100GB 전송 권장)
- 1GB 넘으면: hd만 Cloudflare R2로 이전 (무료 10GB, 전송비 0) — 사이트·포스터·미리보기·sd는 GitHub 유지
- 구글 드라이브는 쓰지 않음: 로그인·바이러스 검사 중간 화면, 요청 한도, 스트리밍용 아님

## 3. 편집 (코드 없이)
1. `python3 src/edit_server.py` → http://localhost:8800/edit.html
2. 작업 선택 → 제목·우선순위·종류 수정
3. 썸네일: 타임라인 스크럽 → 「이 프레임을 썸네일로」
4. 빌보드: 「시작 = 여기」「끝 = 여기」, 표시 시간(초)
5. 홈 순서: 빌보드·대표작·줄 목록 드래그
6. 새 작업: 영상 업로드 → 자동 인코딩·포스터 생성
7. 저장 → 「빌드」 → 커밋·푸시

## 4. 점검
- `python3 src/check.py` → 게시 용량 / 누락 파일 / 데스크톱·모바일 콘솔 오류
- 마지막 결과: 687MB/1000MB(69%), 누락 0, 오류 0

## 5. 도구 체험판 규칙
- 원본 HTML을 복사해 **요청만 가로채 예시 응답**을 돌려줌 (UI·동작은 원본 그대로)
- 원본 사이트·실데이터·Supabase는 건드리지 않음
- 공개본엔 실제 Supabase 주소·키·사내 링크 없음 → 커밋 전 `grep -r "supabase.co\|sb_publishable_" demos/`
