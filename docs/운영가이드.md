# 포트폴리오 사이트 운영 가이드

- 사이트: https://hansy-daangn.github.io/pf/
- 레포: `hansy-daangn/pf` (main 푸시 = 배포, 1~2분)

## 1. 영상은 2개만
| 파일 | 화질 | 쓰는 곳 |
|---|---|---|
| `assets/v/<id>.mp4` | 1080p (긴 변 ≤1920, 파일당 48MB 이하) | 데스크톱 상영관·홈 피처드·전체화면 |
| `assets/v/<id>.sd.mp4` | 720p (긴 변 ≤1280) | 모바일·데이터 절약·호버 확장 카드 |

- 호버 미리보기·홈 피처드는 따로 자른 파일 없이 위 파일을 **정해 둔 초부터** 재생
- 원본이 720p 이하면 `.sd` 없이 1개
- 원본(마스터)은 `masters/`(깃 제외) + `data/media_map.json` → `python3 src/media.py [작품ID]`

## 2. 호스팅
- 지금: GitHub Pages (게시 한도 1GB, 현재 약 75%)
- 넘으면: 1080p 파일만 Cloudflare R2(무료 10GB·전송비 0)로 옮김 — 나머지는 GitHub 유지
- 구글 드라이브는 쓰지 않음: 로그인·바이러스 검사 중간 화면, 요청 한도

## 3. 편집 — 사이트 화면에서 바로 (자동 저장)
- 편집: https://hansy-daangn.github.io/pf/edit/ · 디자인: https://hansy-daangn.github.io/pf/design/
- 처음 한 번만 「저장 연결」: GitHub 토큰(저장소 pf · Contents 읽기/쓰기)을 붙여넣으면 그 브라우저에 기억
- 고치면 화면에 바로 반영 → 1.5초 뒤 자동 저장(GitHub 커밋 1번) → 실제 사이트는 약 1분 뒤 반영

| 하고 싶은 것 | 방법 |
|---|---|
| 카드 순서 | 줄 안에서 카드를 끌어 놓기 |
| 줄 순서 | 줄 제목 왼쪽 ⠿ 손잡이를 위아래로 끌기 |
| 피처드 순서·추가·빼기 | 피처드 아래 칩 끌기 · ＋ · ✕ |
| 피처드 재생 구간 | 영상 아래 빨간 손잡이 두 개 끌기(끄는 동안 그 장면이 보임) |
| 제목·소개·종류 | 글자를 눌러 바로 고치고 Enter |
| 썸네일 | 카드에 마우스 → 「썸네일」 → 필름 스트립·슬라이더로 장면 고르기 → 「이 장면으로」(또는 이미지 올리기) |
| 카드 빼기·더하기 | 카드 ✕ · 줄 끝 ＋ |
| 호버 시작·노출·대표 작업 | 카드를 눌러 상영관 → 아래 편집 줄 |
| 되돌리기 | 아래 바 「되돌리기」 · Ctrl+Z / 다시 Ctrl+Shift+Z |

- 디자인 페이지: 왼쪽에서 모양·슬라이더를 고르면 오른쪽 미리보기(데스크톱·모바일 / 홈·작업·도구·이력서·상영관)에 바로 적용, 자동 저장
- 새 영상 작품 추가·영상 교체는 파일을 채팅으로 보내면 Claude가 인코딩해 넣음

## 4. 레이아웃 규칙
- 사이트 최대 폭 1440px, 좌우 여백 = 화면 폭의 4%(16~64px)
- 피처드: 크기는 디자인 패널 슬라이더(기본 1120px), 가장자리는 배경으로 스며들게(경계 안 보임)
- 카드: 16:9 통일, 세로 영상만 모인 줄만 9:16
- 16:9 카드 썸네일: 직접 고른 16:9 → 포스터가 16:9면 그대로 → 16:9 영상이 있으면 그 장면 → 없을 때만 세로 이미지를 블러 배경 위에

## 5. 점검
- `python3 src/check.py` → 게시 용량 / 누락 파일 / 데스크톱·모바일 콘솔 오류

## 6. 도구 체험판 규칙
- 원본 HTML 복사본에 앞단 스크립트를 넣어 **서버 요청만 예시 응답으로** 바꿈 (UI·동작은 원본 그대로)
- 원본 사이트·실데이터·Supabase는 건드리지 않음
- 공개본엔 실제 서버 주소·키·사내 링크 없음 → 커밋 전 `git grep --cached -E "supabase\.co|sb_publishable_|eyJhbGci"`
- CreativeReporter `demos/cr-live` · KarrotField `demos/kf-live` (관리자 화면 `?as=admin`)
