# 디자인 모듈

- **결론:** 사이트를 8개 모듈로 나눠, 모듈마다 모양만 골라 끼운다. 토큰(색·글자·간격·속도)과 위계는 모두 공유
- **고르는 법:** 사이트 주소 뒤에 `?design` → 오른쪽 아래 「디자인」 패널에서 바로 바꿔 보기 → 「코드 복사」로 조합을 보내 주거나, 로컬 편집 서버에선 「사이트 기본값으로 저장」
- **바꾸는 곳:** `data/design.json`의 `pick` 숫자 1개 → 빌드
- **코드 위치:** 모듈마다 CSS 파일 1개, 그 안에서 `body[data-<모듈>="번호"]` 블록이 모양 하나

| 모듈 | 키 | 지금 | 선택지 | 파일 |
|---|---|---|---|---|
| 피처드 | `feat` | 1 | **1** 풀블리드 / **2** 카드 + 옆 설명 / **3** 풀블리드 + 아래 설명 | `src/css/20-feat.css` |
| 카드 호버 | `hover` | 1 | **1** 확장 카드 / **2** 제자리 재생 / **3** 확대 재생 | `src/css/50-hover.css` |
| 카드 모양 | `card` | 1 | **1** 기본 / **2** 미니멀 / **3** 부드럽게 | `src/css/40-card.css` |
| 카드 크기 | `size` | 2 | **1** 작게 / **2** 기본 / **3** 크게 | `src/css/40-card.css` |
| 줄 화살표 | `arrow` | 1 | **1** 제목 오른쪽 / **2** 줄 양 끝 | `src/css/30-row.css` |
| 상영관 | `theater` | 1 | **1** 시네마 / **2** 오른쪽 정보 | `src/css/70-theater.css` |
| 색 | `theme` | 1 | **1** 라이트 / **2** 홈만 다크 / **3** 전체 다크 | `src/css/00-tokens.css` |
| 움직임 속도 | `motion` | 2 | **1** 빠르게 280ms / **2** 기본 400ms / **3** 여유 520ms | `src/css/00-tokens.css` |

## 구조
```
src/css/00-tokens.css   토큰 + 색(theme) + 움직임 속도(motion)
src/css/10-base.css     리셋 · 레이아웃 폭(1440) · 내비 · 버튼 · 푸터
src/css/20-feat.css     피처드(feat 1·2·3)
src/css/30-row.css      장르 줄 + 화살표(arrow 1·2)
src/css/40-card.css     카드 모양(card 1·2·3) + 카드 크기(size 1·2·3)
src/css/50-hover.css    카드 호버(hover 1 확장 · 2 제자리 · 3 확대)
src/css/60-pages.css    작업 · 도구 · 이력서 페이지
src/css/70-theater.css  상영관(theater 1·2) + 작게 보기
src/css/90-design.css   ?design 패널
```
- 빌드가 `src/css/*.css`를 번호순으로 합쳐 `css/site.css` 하나로 냄
- 새 모양 추가: 해당 파일에 `body[data-<모듈>="4"]` 블록 + `data/design.json` options에 한 줄
- 마크업은 모양마다 따로 만들지 않음 — 같은 HTML을 CSS만 바꿔 씀 (호버 2·3만 JS에서 모드 확인)
