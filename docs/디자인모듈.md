# 디자인 모듈

- **결론:** 사이트를 35개 모듈로 나눠, 모듈마다 모양만 골라 끼운다. 토큰(색·글자·간격·속도)과 위계는 모두 공유. 모든 모듈의 1번(또는 지금 고른 번호)은 지금 모습 그대로
- **고르는 법:** `/design/` 페이지에서 모듈 선택지를 누르면 미리보기에 바로 반영(`PF.applyDesign(pick)`) → 연결돼 있으면 자동 저장
- **바꾸는 곳:** `data/design.json`의 `pick` 숫자 1개 → 빌드(`python3 src/build.py`)
- **코드 위치:** 모듈마다 CSS 파일 1개, 그 안에서 `body[data-<모듈>="번호"]` 블록이 모양 하나. 슬라이더는 `--<키>` 변수
- **선택지 비교 이미지:** `pf_work/design_review2/<키>.jpg` (1440×900, 선택지 번호·이름 표시)

## 새 모듈 동작 메모
- **홈 구성 `homel` 2:** `renderHome`이 `.feat`를 숨기고 `.rows` 맨 앞에 `section.row.tiles[data-row="tiles"]`(대표 작업 앞 3개)를 넣음. 대표 작업 줄은 나머지만. 타일은 호버 모드와 상관없이 제자리 재생. 편집 화면(`/edit`)은 늘 1
- **피처드 전환 `fnav`:** 2 = `featHTML`이 늘 그려 두는 `.frail`(썸네일 줄)을 보이게 · 3 = `Feat`가 칸마다 `--o`(지금 작품과의 거리)를 넣고 CSS가 옆으로 배치, 옆 작품을 누르면 그 작품으로 · 4 = 편집 화면처럼 구간 반복
- **피처드 높이 `feath` 2:** `--featw`를 `(100svh − --peek) × 16/9`로 덮어씀(슬라이더 값 무시). 1440×900에선 여백만 늘고, 큰 화면(1920×1080)에서 차이가 큼
- **카드 비율 `cardar` 2:** 홈 줄 카드만 원본 포스터 + `--ar`(가로/세로)로 그림(`cardHTML(w, cls, {row:true})`). 그리드(줄 레이아웃 2)·첫 카드 크게(3)의 큰 칸·랭킹(4) 줄은 16:9 + 블러 채움으로 둠. 값이 바뀌면 `applyDesign`이 홈을 다시 그림(`homel`도 같음)
- **상영관 전환 `thtr` 2:** `Theater.open(id, {from: 썸네일 요소})` → View Transitions로 썸네일 ↔ 상영관 화면(`.vw`) 모핑. 닫을 땐 연 곳(또는 같은 작품의 보이는 카드)으로 돌아감. 미지원 브라우저·움직임 줄이기·편집 화면은 1과 같음
- **상세 진입 `detail` 2:** 카드 클릭·「상세 정보」 → 상세 창(`.dmod`), 창 안 「재생」 → 상영관. 확장 카드의 「재생」·피처드 「재생」은 바로 상영관
- **줄 제목 `rowhd` 2:** `rowHTML`의 `.hd > span.pgi`를 `mountRows`가 채움(한 화면 = 한 칸)

- 빌드가 `src/css/*.css`를 번호순으로 합쳐 `css/site.css` 하나로 냄
- 새 모양 추가: 해당 파일에 `body[data-<모듈>="번호"]` 블록 + `data/design.json` options에 한 줄. 선택지를 뺄 땐 번호를 다시 매기지 않고 그 번호만 지움(지금 고른 번호의 뜻 유지)
- 마크업은 모양마다 따로 만들지 않음 — 같은 HTML을 CSS만 바꿔 씀. JS가 모드를 보는 곳: 호버 2·3, 피처드 전환 3·4, 카드 비율 2, 상영관 전환 2, 홈 구성 2, 상세 진입 2
- 피처드 공통 법칙: 영상은 자르지 않고, 가장자리는 배경으로 스며들게(mask 페이드), 글자는 페이드된 쪽에. 캐러셀(fnav 3)만 둥근 카드
