# 디자인 모듈

- **결론:** 지금 모습은 확정 — 고른 디자인이 코드의 기본값이고, 고르지 않은 선택지는 코드·데이터에서 지웠다(2026-11-02). 남은 건 미세 조정 슬라이더 6개. 새 디자인 선택지는 이 확정안 위에 새 모듈로 얹는다
- **고르는 법:** `/design/` 페이지에서 슬라이더(또는 새 모듈 선택지)를 바꾸면 미리보기에 바로 반영(`PF.applyDesign(pick)`) → 연결돼 있으면 `data/design.json` 자동 저장
- **값이 들어가는 곳:** `data/design.json`의 `pick` → 빌드(`python3 src/build.py`)·배포(`src/embed.py`)가 body에 넣음. 슬라이더 = `style="--<키>:값"`, 선택지 모듈 = `data-<키>="번호"`

## 새 모듈 추가 방법

1. **1번 = 지금 모습.** 1번은 CSS 규칙을 쓰지 않는다(지금 코드 그대로). 2번부터 `body[data-<키>="2"] …` 블록으로 바뀌는 것만 덮어쓴다
2. **CSS:** 새 파일 `src/css/8x-<키>.css`(묶음 접두어 81~85 — 빌드가 번호순으로 합치므로 기본 파일들보다 뒤에 붙어 이김). 맨 위 주석에 선택지 번호와 한 줄 설명
3. **데이터:** `data/design.json`
   - `modules.<키>` = `{"name": "보이는 이름", "file": "src/css/80-<키>.css", "options": {"1": "이름 — 설명", "2": "이름 — 설명"}}` (설명은 ` — ` 뒤, /design에서 작은 글씨로 보임. 내부 키는 화면에 안 보임)
   - `pick.<키>` = 1
   - 슬라이더라면 `{"name", "file", "type": "range", "min", "max", "step", "unit"}` → CSS에서 `var(--<키>, 기본값)`
4. **JS가 모드를 봐야 할 때만** `document.body.dataset.<키>`로 분기(편집 화면 `/edit/`은 영향받지 않게 `EDIT`일 땐 1처럼). 마크업이 달라지는 모듈이면 `applyDesign`에서 값이 바뀔 때 `renderHome()`을 다시 부르게 한다
5. **선택지를 뺄 땐** 번호를 다시 매기지 않고 그 번호만 지움(저장된 pick의 뜻 유지)
6. **확정할 땐** 고른 번호의 규칙을 `body[data-…]` 조건 없이 기본 파일에 합치고(우선순위가 낮아져 다른 규칙에 지지 않는지 확인), 나머지 번호·모듈 항목·JS 분기를 지운다 — 이번(2026-11-02)과 같은 방식. 비교: `/home/claude/pf_work/lock/`(snap.py 전·후 스크린샷 + 계산된 스타일 비교)
