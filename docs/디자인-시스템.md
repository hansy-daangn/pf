# 디자인 시스템

원칙: **피그마 원본이 아이덴티티다.** 새 요소는 만들지 않고, 아래 스케일에서만 고른다.
불필요한 요소(장식 선·그림자·운영 설명)는 기본값이 "없음"이다.

## 색 (전부 CSS 변수, index.html `:root`)
| 토큰 | 값 | 용도 |
|---|---|---|
| 흰 배경 | `#ffffff` | 라이트 섹션 (이력서·새로운 조합) |
| `--dark` | `#101013` | 다크 섹션 (C1·C2·갤러리) |
| `--ink` | `#111114` | 라이트 본문 |
| `--red` | `#a61c2f` | 레드박스(사진 뒤) |
| `--red2` | `#cc1433` | 강조 (태그라인·목차 라벨·CTA) |
| `--wine` | `#7f0036` | 슬로건 강조 단어 바탕 (+ 핑크 텍스처 screen 블렌드) |
| `--tlab` | `rgba(0,0,0,.5)` | 라이트 보조 텍스트 |
| 다크 보조 | `rgba(255,255,255,.6)` | 다크 보조 텍스트 |

## 타이포 (Pretendard Variable 하나만)
| 역할 | 크기(데스크톱) | 굵기 | 비고 |
|---|---|---|---|
| 슬로건 | 96px | 800 | `새로운 조합, 새로운 의미.` 전용 |
| 이력서 섹션 헤더 | 36px | **200** | 피그마 시그니처 (큰 글자만 얇게) |
| 태그라인 | 36px | 800 | 빨강 강조 + 검정 |
| 챕터/블록 타이틀 | 40px | 800 | C1·C2·갤러리 제목 |
| 본문 | 16–18px | **300** | 웹 가독성 때문에 200→300 (피그마는 200) |
| 표 (수상) | ≤13.5px | 300 | 6열이 스크롤 없이 들어가는 크기 |
| 캡션/메타 | 11–12px | 300–400 | |

규칙: 얇은 굵기(200)는 22px 이상에서만. 본문은 300 미만 금지.

## 간격
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 스케일만 사용. 섹션 상하 여백은 `clamp(48px, 9vh, 110px)`.

## 모서리·그림자
- 모서리: 신분카드·사진 21px (피그마), 갤러리 카드 12px, 그 외 0.
- 그림자: **콘텐츠 영역에서 금지.** 모달·라이트박스 같은 떠 있는 UI만 허용.

## 반복 구조 (위계의 법칙)
`빨간 라벨(좌) + 볼드 타이틀 + 얇은 부제(우)` 그리드 한 가지가
첫 페이지 목차 → C1/C2 챕터 헤더 → lab.html 아이템까지 반복된다. 새 섹션도 이 구조를 쓴다.

## 시그니처 (이 사이트를 기억하게 하는 것)
1. 핑크 블롭 + 증명사진 신분카드 (이력서)
2. 슬로건 강조 단어의 와인색+핑크 텍스처 `background-clip:text`
3. 다크 챕터의 원본 움짤(물결·AE 데모)이 그 자리에서 실제로 움직이는 것
