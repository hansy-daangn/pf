# 포트폴리오 사이트 — 문서 인덱스

> 이 폴더는 옵시디언 볼트로 열 수 있습니다. 사이트의 모든 작업 맥락·디자인 규칙·할 일이 여기 있습니다.
> 루트의 `맥락.md`는 AI 협업용 전체 히스토리, 이 폴더는 사람이 읽는 정리본.

## 문서
- [[디자인-시스템]] — 색·타이포·간격·컴포넌트 규칙. 새 요소를 만들 땐 반드시 이 스케일에서만 고른다.
- [[백로그]] — 디벨롭 지점과 진행 상태. 새 아이디어는 여기에 먼저 적는다.
- [[결정-로그]] — "왜 이렇게 했는가"의 기록. 뒤집을 땐 여기부터 확인.
- [[변경-기록]] — 무엇이 언제 바뀌었는지. 날짜순.

```
(#lab)       도구 · 연구 — index.html 내 섹션 (CreativeReporter·AI 파이프라인 실물/구조도 포함)

```

## 편집 모드 (소유자 전용)
- 활성화: 페이지 아무 곳에서나 키워드 **`hansy`** 를 타이핑 (또는 URL 뒤에 `#hansy`)
- ✎ 버튼 → 모든 글 클릭 편집 → ✔ 저장 (GitHub `content.json`에 즉시 커밋, 약 30초 후 전 기기 반영)
- 갤러리: 편집 모드에서 카드 클릭 → 소재 관리(숨기기/보이기/삭제/소재 추가)
- 새 작업 업로드: 편집 모드 → `＋ 작업 추가` → 파일 + 제목·설명·분류·비율 → GitHub에 영구 저장
- 크기 조절: 편집 모드에서 컬럼 경계의 빨간 핸들 드래그(이력서/히어로/C1/C2), 갤러리 필터 옆 간격 슬라이더, 증명사진은 드래그(위치)·휠(확대) — 저장 시 영구 반영
- 저장 권한: Fine-grained PAT (hansy-daangn/pf, Contents RW) — 최초 1회 입력, 브라우저에 기억
